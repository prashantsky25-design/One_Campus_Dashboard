# Campus Dashboard with Smart Attendance System

A modern **College Campus Dashboard** designed to simplify and digitize essential campus services through a single platform. This project integrates a **Dynamic QR Code-based Smart Attendance System**, secure user authentication, fee payment, student ID card access, club information, hackathon updates, and more to enhance the overall student experience.

---

## 🚀 Features

 🔐 **Secure User Authentication**

  * Login system for authorized users.

 📱 **Dynamic QR Code Smart Attendance**

  * Generates dynamic QR codes for attendance.
  * Students can mark attendance securely by scanning the QR code.
  * Designed to reduce proxy attendance and improve accuracy.

 💳 **Fee Payment Portal**

  * Easy access to fee payment services.

 🆔 **Digital Student ID Card**

  * View student ID card digitally within the dashboard.

 🎯 **College Clubs**

  * Explore various technical and non-technical clubs.
  * Access club information and activities.

 🏆 **Hackathon Section**

  * View upcoming hackathons and competitions.
  * Stay updated with innovation events.

 📞 **Contact Us**

  * Quick access to college contact information and support.

 📱 **Responsive Dashboard**

  * Clean and user-friendly interface optimized for different screen sizes.
